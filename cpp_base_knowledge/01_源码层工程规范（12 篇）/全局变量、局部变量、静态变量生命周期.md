# 全局变量、局部变量、静态变量生命周期

## 一、核心分类与内存段归属（底层本质）

C/C\+\+ 所有变量的行为、生命周期、初始化特性，完全由**存储类型**决定，最终对应程序 ELF 不同内存段：

- **全局变量**：存储在 data / bss 段，进程全局可见

- **局部变量（普通自动变量）**：存储在栈 stack 段，函数栈帧内有效

- **静态全局变量 static**：data / bss 段，仅当前文件可见

- **静态局部变量 static**：data / bss 段，函数内可见、进程常驻

所有 static 修饰变量、全局变量**不占用栈空间**，均属于进程全局数据区。

## 二、局部变量（自动变量 auto）完整机制

### 1\. 作用域

仅在**当前函数/代码块**内有效，出花括号直接失效。

### 2\. 生命周期

函数调用、栈帧创建时分配栈内存；函数返回、栈帧销毁时**立即释放内存**。

### 3\. 初始化特性

**不会默认清零**，未手动初始化则为随机脏值，存在脏数据风险。

### 4\. 工程特性

- 分配速度极快，仅栈指针偏移

- 不产生全局内存常驻，内存开销极小

- 无法跨函数、跨调用保存数据

```c
void func() {
    int a; // 栈变量，随机脏值
    int b = 10; // 栈变量，手动初始化
} // 出作用域 a、b 内存全部释放

```

## 三、全局变量完整机制

### 1\. 作用域

**整个工程所有文件可见**，跨文件可通过 extern 引用。

### 2\. 生命周期

进程启动加载时分配内存，**全程常驻内存**，进程销毁才释放。

### 3\. 初始化特性

全局变量默认**自动零初始化**：未赋值默认值为 0、空指针、false。

### 4\. 内存段分配规则

- 已初始化全局变量 → **data 段**

- 未初始化全局变量 →**bss 段**（不占用磁盘空间，运行时统一清零）

### 5\. 工程坑点

全局变量过多会导致**程序内存常驻量大、耦合严重、线程不安全**，多线程场景极易触发数据竞争。

## 四、静态局部变量 static（高频核心考点）

### 1\. 作用域

仅**当前函数内部可见**，外部无法访问，隐藏性极佳。

### 2\. 生命周期

首次调用函数时初始化分配内存，**进程生命周期永久常驻**，函数退出不释放、不重置。

### 3\. 初始化规则

- 默认自动零初始化

- **仅初始化一次**，后续函数调用直接复用上次值

- 初始化发生在程序加载阶段，非函数运行阶段

```c
void count() {
    static int num = 0; // 仅首次执行初始化
    num++;
    printf("%d\n", num);
}
// 连续调用输出：1 2 3 4... 持续累加不重置

```

### 4\. 本质

栈作用域 \+ 全局生命周期：**藏在函数里的全局变量**。

## 五、静态全局变量 static

### 1\. 作用域

**仅限当前 \.c/\.cpp 文件内部**，跨文件无法通过 extern 引用，彻底隔离文件域。

### 2\. 生命周期

同全局变量，进程全程常驻内存。

### 3\. 工程价值

实现**文件级私有变量**，避免全局命名污染、跨文件符号冲突，是模块化编程核心手段。

## 六、extern 跨文件引用机制

**extern 是声明，不是定义**：仅告诉编译器变量存在、类型是什么，不分配内存。

真正的内存分配来自全局变量定义，一个工程**只能有一处定义**，多处定义触发多重定义链接报错。

```c
// a.c
int g_val = 100; // 定义，分配内存

// b.c
extern int g_val; // 声明，引用外部变量

```

static 全局变量无法被 extern 引用，实现彻底隔离。

## 七、四种变量核心对比总表

- **普通局部变量**：栈内存、块作用域、随用随毁、脏值、无常驻

- **静态局部变量**：数据段、函数作用域、进程常驻、一次初始化

- **全局变量**：数据段、工程全局可见、进程常驻、默认清零

- **静态全局变量**：数据段、文件私有、进程常驻、无符号冲突

## 八、工程高频报错与隐患

### 1\. 返回局部变量指针（经典致命错误）

局部变量栈内存函数退出即销毁，返回野指针，后续访问内存错乱。

### 2\. 静态变量多线程数据错乱

static 变量全局唯一，多线程同时读写无锁会引发数据竞争。

### 3\. 全局变量滥用导致内存泄漏、状态耦合

大量全局常驻内存无法释放，程序长期运行内存占用持续走高。

### 4\. 误以为局部变量默认清零

局部变量无自动清零，未初始化直接使用会出现随机逻辑 bug。

## 九、工程最佳规范

1. 优先使用局部变量，最小化内存占用与耦合；

2. 需要函数记忆状态，使用 static 局部变量；

3. 需要文件私有全局数据，使用 static 全局变量；

4. 尽量少用裸全局变量，规避多线程竞争与全局状态耦合；

5. 禁止返回局部变量指针/引用。
